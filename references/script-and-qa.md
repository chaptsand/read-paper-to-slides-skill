# Script and Q&A

## Anchor the script

Use the actual final deck as the page sequence and visible-content reference. Use the paper and verified understanding record to check facts. Confirm the file identity, page count, and page order from available content before claiming full alignment.

If the deck is unavailable, request it. Continue with a clearly provisional script only when usable slide text or an authorized outline exists. Never claim to match inaccessible slides. If a supplied deck contains a factual error, flag and correct the affected content within the requested scope before rehearsing that claim.

For a script-only request, do not redesign a sound deck. Do not insert unseen result tables, new methods, or extra sections that require new slides.

## Write page by page

Use headings that match actual slide numbers and titles. Cover all requested pages exactly once. Write connected, speakable Chinese prose by default, keeping stable English technical terms.

On each page, introduce the visible subject, explain its key mechanism or comparison, state the supported takeaway, and connect naturally to the next page. Adjust this pattern to the content; do not use identical opening and closing sentences throughout.

Explain what the audience should look at in a figure or table. Do not read every cell or recite displayed bullets. Explain equations through their purpose, objects, and operations rather than reading all symbols aloud.

Use small teaching clarifications that remain consistent with the deck and paper. Identify inference or an illustrative example in spoken language. Keep unverified implementation details and speculative mechanisms out of factual narration.

Use pause, emphasis, pointer, and page-turn cues sparingly when they help rehearsal. Keep cues distinct from spoken text. Prepare transitions that follow the actual page sequence.

## Respect the timing constraint

Use an established duration limit when available. Estimate timing from the spoken content, technical density, and pauses, and label it as an estimate. If a rehearsal pace or recording duration exists, prefer that evidence over a generic speaking rate.

Allocate more time to method and essential results. Keep background and secondary examples proportionate. Allow a practical buffer for page turns and pauses when there is a strict cap. Shorten repetition and low-priority detail before compressing necessary definitions or qualifications.

Do not guarantee a duration from word count alone. Without a time budget, provide the requested script without inventing one.

## Prepare audience questions

Select questions arising from the actual paper and audience: task and biological meaning, component relationships, equations, evaluation, baseline fairness, ablations, limitations, implementation uncertainty, and transfer to another research problem when relevant.

Give a short answer first, then a deeper explanation if useful. Attach evidence locations to factual claims. State what the paper does not resolve and what additional check or experiment would answer it. Do not turn a plausible extension into an author claim.

Prioritize the user's unresolved questions and points where the deck simplifies the method. Avoid a generic interview-question list unrelated to the presentation.

## Final checks

Check page count and order, terminology, visible numerical values, metric interpretation, conclusion scope, transitions, and any requested timing estimate. Check prose punctuation and dollar-delimited mathematics throughout, including source notes. Ensure late corrections in the deck are reflected in the matching script passages.

Report source or slide gaps plainly. Deliver the complete requested script or Q&A set; do not provide only an outline when a full draft was requested.
